# 协议、开漏与时间缩放

## 开漏总线

I2C/SMBus 等总线的设备只能拉低或释放。wrapper 中使用 `tri1`、上拉模型或多个高阻驱动表达：

```text
drive_low ? 1'b0 : 1'bz
```

不要用逻辑 1 表示释放，否则会掩盖争用、ACK 和时钟拉伸问题。

## 超时

以下操作都必须有周期上限或 `with_timeout()`：

- 等待复位完成；
- 等待时钟边沿或状态迁移；
- 等待 ACK、响应或中断；
- 后台从机、monitor 和 scoreboard 任务。

超时时报告当前状态、事务序号、最近信号值和仿真时间，确保测试不会无限挂起。

## 参数加速

允许缩短分频、滤波和协议 timeout 以提高仿真速度，但保持：

- CDC 同步级数和相对时钟关系；
- 数字滤波所需的稳定采样数；
- 协议最小高低电平比例；
- DUT 能实际观察到的脉冲宽度；
- master、slave 和 checker 使用一致的时间尺度。

先计算缩放后的最短相位是否仍能通过输入滤波，再运行测试。不要把参数压缩到改变协议语义。

## 时钟与复位

- wrapper 显式声明 `timescale`。
- 测试明确复位有效电平、同步/异步方式和释放边沿。
- 对跨时钟激励保留足够稳定时间，不在同一仿真 delta 中制造非真实事件。
- CDC 正确性不能只靠一次功能仿真证明；需要时结合结构检查、断言或专用 CDC 工具。
